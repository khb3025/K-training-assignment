## 구조 설명

### 모듈 구성
- BoundedContext : 각 모듈이 독립적으로 관리되며, 각 모듈 사이에 정보를 공유하지 않는 공간 
- share : 각 모듈이 독립적으로 관리되나, boundedContext내 서로 관련된 모듈이 자유롭게 공유할 수 있는 공간
- global : share는 모듈과 모듈 사이의 관계에 의해 정보를 공유하나, global은 어느 모듈이건 간에 자유롭게 정보를 취득할 수 있는 공간
- in : Controller, Secheduler, Listener
- out : repository, ApiClient
- app : facade, usecase 등 비지니스영역
- domain : entity, 정책 등 순수 비지니스 영역

### 이벤트와 HTTP API를 구분한 이유
- 이벤트 : 전파에 특화, 반환결과가 필요 없을때 사용 ( 사건의 발생만을 전달 )
- HTTP API : 반환결과가 필요할때 사용 ( 요청에 대한 응답을 전달 )

### 회원 복제 흐름
- 회원가입 -> 회원가입 로직 내 EventPublisher 가 MemberJoinedEvent 발행 -> post 바운디드 컨텍스트의 PostEventListenr가 회원가입 이벤트 감지
  -> 발행된 이벤트에서 전달받은 MemberDto를 이용하여, PostMember 를 동기화 및 저장
